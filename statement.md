# Project Statement

## Problem Statement

Traditional mystery and detective games often focus on entertainment without providing a simple way to demonstrate programming concepts through an interactive application.

The purpose of this project is to develop a command-line based sci-fi detective game in Java that combines an investigation-based storyline with core programming concepts. The player investigates a mysterious incident on Nova Station by exploring locations, collecting evidence, questioning suspects, solving puzzles, and making a final accusation.

The project provides an interactive way to demonstrate object-oriented programming, modular design, collections, conditional logic, input handling, and basic problem-solving using Java.

## Scope

The project focuses on developing a single-player command-line investigation game.

The scope of the project includes:

- Creating and managing a player character
- Providing an interactive investigation menu
- Allowing the player to explore different locations
- Collecting and managing evidence
- Maintaining a player inventory
- Providing suspect profiles and interviews
- Comparing suspect statements with collected evidence
- Providing puzzles that affect investigation progress
- Unlocking locations based on completed investigation tasks
- Tracking investigation progress
- Allowing the player to make a final accusation
- Providing different outcomes for correct and incorrect accusations
- Handling invalid user input appropriately

The current version is limited to a command-line interface and a single investigation case. Features such as a graphical interface, multiple cases, images, sound, and advanced game mechanics are outside the current scope and may be considered for future development.

## Target Users

The primary target users of this project are:

- Students learning Java and object-oriented programming
- Beginners interested in understanding programming through interactive applications
- Users who enjoy simple mystery and investigation-based games
- Faculty or evaluators reviewing a Java course project

## High-Level Features

### 1. Location Exploration

The player can explore different locations on Nova Station and investigate areas for useful information and evidence.

### 2. Evidence Management

The game allows the player to collect, store, and view evidence discovered during the investigation.

### 3. Suspect Investigation

The player can view suspect information and question suspects to obtain statements that may help solve the case.

### 4. Puzzle Solving

The player must solve an investigation-related security puzzle to unlock restricted areas and access additional evidence.

### 5. Investigation Progress

The game tracks collected evidence, questioned suspects, and solved puzzles to represent the progress of the investigation.

### 6. Case Resolution

After gathering sufficient information, the player can accuse one of the suspects. The game evaluates the accusation and displays whether the case has been solved or remains unresolved.
